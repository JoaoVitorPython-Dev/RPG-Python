# RPG de Terminal em Python

Um RPG de terminal desenvolvido em Python como projeto de aprendizado e prática de programação.

O jogo possui um sistema básico de batalha, níveis, experiência, moedas e inventário. O projeto será desenvolvido aos poucos, recebendo novas funcionalidades conforme o aprendizado em Python avançar.

## Versão atual

### Versão 1.0

RPG de terminal com sistema básico de:

* Batalhas
* Níveis
* Experiência (EXP)
* Moedas
* Inventário
* Status do personagem
* Sistema de fuga durante as batalhas

## Como executar

### 1. Instale o Python

Certifique-se de que o Python esteja instalado no seu computador.

### 2. Baixe o projeto

Baixe ou clone este repositório para o seu computador.

### 3. Abra a pasta do projeto

Abra a pasta do projeto no VS Code ou em outro editor de código.

### 4. Execute o jogo

Abra o terminal na pasta do projeto e execute:

```bash
python rpg.py
```

Caso o comando acima não funcione no Windows, tente:

```bash
py rpg.py
```

O jogo será iniciado diretamente no terminal.
